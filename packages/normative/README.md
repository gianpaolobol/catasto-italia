# Registro fonti normative 0.1.0
Registro di ricerca, non parere o motore di vigenza. I record contengono revisioni documentali interne, non certificano il testo vigente. effectiveFrom è la decorrenza storica reperita, non una conferma di applicabilità; effectiveUntil null significa fine non accertata. Intervallo [inizio, fine). Una ricerca per provincia usa national o provincia esatta; non risolve deroghe. Nessun record historical/pending abilita una regola. L'allowlist dei domini è un controllo sintattico, non autenticazione del contenuto. Non caricare cataloghi da fonti non fidate. Test: node --test tests/normative.test.mjs. Prossima versione: verifica consolidata, supersessioni, ambiti e conflitti, fonti territoriali, processo di abilitazione documentato.
